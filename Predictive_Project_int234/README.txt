ShopperAI — Light HTML Dashboard

This version uses the actual Online Shoppers dataset and reproduces the chart structure from the Python/Streamlit project in a light HTML/CSS/JS interface. Donut charts now show labels and percentages directly, without requiring hover.

Run:
1. Open this folder in VS Code.
2. Start a local server: python3 -m http.server 8000
3. Open http://localhost:8000

The prediction page remains a browser-side demo heuristic. The charts and model metrics are based on the Python pipeline and dataset.
